# video_sub_fix — 视频字幕校对与修复 Skill

> 一个用于修复视频平台自动生成字幕（ASR 字幕）的 AI Skill。
> 以视频画面截帧 OCR 字幕为主要校对依据，通过连续帧交叉验证，恢复视频中实际说出的、最完整且最准确的原话。

---

## ✨ 它能做什么

视频平台（B站、YouTube 等）的自动字幕由语音识别（ASR）生成，常常存在各种问题。本 Skill 通过对比两份材料来修复它们：

| 材料 | 来源 | 作用 |
|---|---|---|
| **平台字幕** | 视频平台 ASR 自动生成 | 作为基准（含时间轴） |
| **截图字幕** | 定时截帧（约每 0.3 秒）后 OCR 识别 | 作为主要校对依据 |

可以修复的问题包括：

- ✅ 同音字 / 错别字
- ✅ 漏字、多字
- ✅ 人名、机构名、专有名词错误
- ✅ 数字错误
- ✅ 断句错误
- ✅ 句子不完整（利用连续帧补全）
- ✅ ASR 听错导致的整句错误

## 🔗 配套工具：videoshottosub

本 Skill **强烈建议**与以下开源工具配合使用：

> **📦 [ylhcqN/videoshottosub](https://github.com/ylhcqN/videoshottosub)**

### 为什么需要它？

本 Skill 需要「截图字幕」作为校对依据，而 **videoshottosub 正是负责生成这份材料的工具**。它可以对视频进行定时截帧（约每 0.3 秒一张），并从截图中识别出画面上的字幕文字。

### 推荐工作流
* Step 1  从视频平台下载 ASR 自动字幕（SRT/VTT/TXT）和视频 
* Step 2  用 videoshottosub 对视频定时截帧 + OCR → 得到截图字幕（带时间信息的识别结果）
* Step 3  将两份材料一起提供给 video_sub_fix Skill
* Step 4  Skill 自动合并重复帧、排除画面干扰、
* Step 5  交叉验证 → 输出修复后的字幕 



## 🚀 使用方法
### 准备材料：
  平台 ASR 字幕文件（SRT / VTT / TXT / CSV / JSON 均可）
  videoshottosub 生成的截图 OCR 字幕结果
  将两份材料一起发给 AI，例如：
    「请用 video_sub_fix 帮我修复字幕。以下是平台字幕和截图 OCR 字幕，请输出修复后的成品字幕。」
  获得结果
    默认输出：修复后的字幕（保留原时间轴格式）
    可选输出：修改对照表（说明每处改动的原因）
##🧠 核心原则
* 截图字幕优先，但不迷信：OCR 也会出错，必须综合多个连续帧判断，采用「多帧一致 + 最完整」的版本。
* 排除画面干扰：自动识别并剔除水印、台标、弹幕、标题、背景文字等非说话内容。
* 不润色：这是字幕修复，不是文字美化。保留人物的口语表达（「这个」「然后」、口头重复等），不改写说话风格。
* 不虚构：严禁凭空补充人名、数字、事件，严禁用网络搜索结果或模型自身知识覆盖用户提供的材料。无法确认的内容会标记 [存疑：XXX]。
* 保留原时间轴：除非有明确证据且用户要求，不重新生成时间轴。
